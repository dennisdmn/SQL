# SELECAO

Pasta destinada a exemplos de consultas SQL com foco em leitura de dados.

## Conteúdos esperados

- Consulta de tabela inteira.
- Seleção de colunas específicas.
- Uso de alias para tabelas e colunas.
- Filtros com `WHERE`.
- Filtros com `IN`, `OR`, `LIKE` e operadores relacionais.
- Cuidados básicos de performance em consultas.

## Observação

Os scripts desta pasta podem conter exemplos em T-SQL ou SQL genérico. Antes de reutilizar, ajuste a sintaxe ao banco utilizado.
