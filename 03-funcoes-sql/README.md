# 03 - Funções SQL

Catálogo de exemplos de funções e construções comuns em SQL Server.

## Conteúdos

- Contagem de linhas: `COUNT`.
- Texto: `UPPER`, `LOWER`, `LEFT`, `RIGHT`, `CHARINDEX`, `LEN`, `SUBSTRING`, `LTRIM`, `RTRIM`, `TRIM`, `REPLACE`, `CONCAT`, `REPLICATE`.
- Números: `ABS`, `ROUND`, `FLOOR`, `CEILING`.
- Datas: `GETDATE`, `CONVERT`, `DATEPART`, `DATEADD`, `DATEDIFF`.
- Nulos: `IS NULL`, `IS NOT NULL`, `ISNULL`, `COALESCE`.
- Condicionais: `CASE WHEN`.
- Ordenação: `ORDER BY`.
- Funções próprias: `CREATE FUNCTION`.

## Dica de uso

Use este arquivo como uma caixa de ferramentas. Copie o bloco que precisa, ajuste a tabela/coluna e valide o resultado em uma amostra antes de aplicar em produção.
