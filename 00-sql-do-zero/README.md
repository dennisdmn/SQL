# 00 - SQL do Zero

Este módulo cobre o caminho inicial antes das consultas analíticas: criar banco, criar tabela, inserir dados, consultar, alterar e apagar com segurança.

## Objetivo

Dar uma base para quem ainda está começando e precisa entender o ciclo completo de uma tabela.

## Conteúdos

- O que é banco, schema, tabela, coluna e linha.
- Tipos de dados básicos.
- `CREATE DATABASE` e `CREATE TABLE`.
- `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL` e `DEFAULT`.
- `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE` e `DROP`.
- Transação simples com `BEGIN TRAN`, `COMMIT` e `ROLLBACK`.

## Ordem sugerida

1. Rode os blocos de criação.
2. Insira dados pequenos.
3. Consulte com `SELECT`.
4. Teste `UPDATE` e `DELETE` dentro de transação.
5. Só depois avance para joins e agregações.
