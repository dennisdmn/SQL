# SALDOS

Pasta destinada a exemplos de cálculo de saldo, valores acumulados e funções de janela.

## Conteúdos esperados

- Saldo acumulado com `SUM()`.
- Uso de `OVER()`.
- Uso de `PARTITION BY`.
- Uso de `ORDER BY` dentro de funções de janela.
- Cálculos auxiliares com `ABS()` e `ROUND()`.

## Aplicações práticas

Esses exemplos são úteis para:

- conciliação bancária;
- controle de movimentações financeiras;
- cálculo de acumulado por conta contábil;
- conferência de saldo por empresa, conta ou centro de custo;
- análises de Controladoria e FP&A.
