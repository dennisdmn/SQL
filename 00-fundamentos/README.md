# 00 - Fundamentos

Esta pasta guarda conceitos pequenos que ajudam a ler, manter e documentar scripts SQL.

## Conteúdos

- Comentário de uma linha com `--`.
- Comentário de múltiplas linhas com `/* ... */`.
- Uso de comentários para testar ou desativar colunas durante a construção de uma consulta.

## Boas práticas

- Comente o motivo de uma regra de negócio, não apenas o que a linha já mostra.
- Evite deixar colunas comentadas sem explicação em scripts finais.
- Em consultas compartilhadas, use aliases claros para tabelas e colunas.
