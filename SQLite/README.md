# SQLite

Pasta destinada a exemplos específicos de SQLite.

## Conteúdos esperados

- Consulta de metadados do banco.
- Listagem de tabelas.
- Comandos administrativos simples.
- Exemplos que não são necessariamente compatíveis com T-SQL, Oracle SQL ou PostgreSQL.

## Atenção

Scripts desta pasta podem conter sintaxe exclusiva de SQLite. Antes de reaproveitar em outro banco, valide a equivalência do comando.
